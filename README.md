# The Last Guardian

A 2D action-defense game developed with **Unity and C#**, where the player takes the role of a guardian protecting a vulnerable character from incoming enemies.

The project focuses on implementing player movement, combat, enemy AI, animations, object protection, enemy spawning, and game-state management in Unity.

## 🎮 Game Overview

**The Last Guardian** is a 2D combat game in which the player must defend a protected character from waves of enemies.

The player can move around the environment, attack enemies, and protect the target until all enemies have been defeated.

## ✨ Features

* 🧍 Player movement and jumping
* ⚔️ Player attack system
* 👾 Enemy spawning and AI
* 🎯 Enemy targeting and movement
* 🛡️ Protected character/object system
* ❤️ Damage and health system
* 💥 Damage feedback and animations
* 🎬 Player and enemy animation systems
* 🏆 Victory system after defeating all enemies
* 📊 Kill counter and game UI
* 🔄 Enemy respawning system
* 🎮 Unity Input System integration
* 🌄 2D environment with layered backgrounds

## 🧩 Main Systems

### Player System

Handles:

* Movement
* Jumping
* Attacking
* Animation states
* Player damage/death

### Enemy System

Handles:

* Enemy movement
* Target detection
* Attacking
* Damage
* Death
* Enemy animations

### Object Protection System

A protected character/object must survive while the player deals with incoming enemies.

### Enemy Respawn System

Controls enemy creation and tracks defeated enemies to determine when the player has successfully completed the level.

### UI System

Displays gameplay information such as:

* Kill count
* Victory screen
* Game status
